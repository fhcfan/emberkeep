Emberkeep is a lantern-keeper arcade survival game: keep your light burning through the night, pulse back the shadow wisps that hunt it, gather golden embers to feed the flame, and survive wave after wave. Pure static HTML, CSS and JavaScript — no libraries, no network, no build step.

You are the keeper of the last lantern in a night garden. WASD or the arrow keys move, Space or a click pulses a ring of light that destroys the wisps closing in — but every pulse burns light, and the lantern drains as you walk. Embers restore light and raise your combo; clearing a wave heals a heart. Three hearts, then the light fades.

## Run it

```sh
cd game && python3 -m http.server 8080
# open http://localhost:8080
```
